# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Mentors (logging sessions on-the-go via mobile) and Admins (managing reports on desktop).

## Product Purpose
An LMS designed to track mentoring sessions, generate branded PDF monthly reports, and automatically email them to parents in one click.

## Positioning
A streamlined, automated workflow that reduces manual reporting overhead into a single-click PDF generation and dispatch process.

## Operating Context
Mentors use the application on mobile devices immediately after sessions to input logs. Administrators use the dashboard on desktop to track progress and send out monthly updates to parents.

## Capabilities and Constraints
Uses Puppeteer for PDF generation and Nodemailer for SMTP email delivery. Protected by PIN access for mentors and password authentication for admins.

## Brand Commitments
"Teman Belajar" and "Krya". Uses existing logo assets (`Logo-Teman-Belajar.png` and `krya-logo.png`).

## Evidence on Hand
Existing Next.js codebase, Tailwind configurations, MySQL database schema, and logo assets.

## Product Principles
1. Fast and frictionless data entry for mentors on mobile.
2. Professional and automated communication with parents.
3. Centralized oversight and control for administrators.
